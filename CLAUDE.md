# Journaling Door Workflow Claude Contract

Read `AGENTS.md` first. Use the discoverable skills under `skills/*/SKILL.md` for capture, application, audit, and dynamic workflows.

When the user asks to “run a workflow,” use the smallest native team that can prove the claim: scout, bounded worker, and independent verifier. If a native runtime is available, use its documented roles; otherwise leave a plan and say that no agents were launched. Never convert a plan into a run claim.

Keep all receipts and evidence inside the repository. A blocked or failed role requires a reason and `replan-workflow` before retrying. Preserve unresolved human decisions, source lineage, and privacy boundaries. Do not send, publish, deploy, commit, push, or write externally without explicit action-time authorization.
